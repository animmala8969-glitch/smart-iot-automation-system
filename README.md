# Smart IoT Automation System

## Overview
This project is a Smart Temperature Control System developed using Arduino UNO and simulated in Tinkercad.

The system automatically monitors temperature using a TMP36 sensor and activates alerts when the temperature exceeds a predefined threshold.

## Features
- Real-time temperature monitoring
- Automated LED and buzzer alerts
- IF/ELSE automation logic
- Serial Monitor output
- Tinkercad simulation

## Components Used
- Arduino UNO
- TMP36 Temperature Sensor
- LED
- Piezo Buzzer
- Resistor
- Breadboard

## Technologies Used
- Arduino IDE
- Embedded C
- Tinkercad

## Applications
- Smart cooling systems
- Industrial monitoring
- Server room safety systems
- Home automation

## Project Output
The system:
1. Reads temperature continuously
2. Displays live readings
3. Activates alerts above threshold temperature
